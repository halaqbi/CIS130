Debugging diagnosis and smallest useful corrections:
The original a:visited color was #f5f1f8, which also was the body background.
The diagnosis was correct: visited links could disappear into the page.
The visited color was changed to #6b5b95, and the normal link color was
changed to a darker pink, #91416a. Matching hover and focus rules now include
a visible outline and background.
The image floated right but had its horizontal margin on the right. Moving
that margin to the left separates the image from the text beside it.
The original clear on main could not clear an image inside main. Each section
now clears earlier floats and contains its own floated image with
"display: flow-root". This rule makes the section's box include the floated
image, so its border surrounds the image and following sections stay below.
The image named yoga.jpg contained AVIF data. It was converted to a real JPEG
while keeping its filename and appearance. Its alt text now describes the
actual floral illustration rather than suggesting a photograph.

Reflection on a useful AI contribution:
The assistant compared the existing website with the assignment and found
issues that a simple list of required CSS properties would miss. In
